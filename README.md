# Stunt Racer

Gioco di corse 3D in stile anni '80, ispirato a *Stunt Car Racer*: piste sopraelevate senza guardrail, salti, turbo e danni al telaio, contro un avversario su tre giri.


**Gioca ora:** https://guitarman344.github.io/stunt-racer/
Un solo file HTML, nessuna dipendenza: apri `index.html` nel browser oppure attiva GitHub Pages sul repository.

## Comandi

| Tasto | Azione |
|---|---|
| ↑ / W | accelera |
| ↓ / S | frena |
| ← → / A D | sterza (solo a terra) |
| Spazio | turbo (riserva limitata) |
| P | pausa |
| M | audio on/off |

Su telefono compaiono i pulsanti a schermo.

## Piste

- **Dorso di Mulo**: gobbe in serie e un dosso enorme a metà giro.
- **Il Ponte Rotto**: due rampe sul vuoto, servono almeno 30 m/s per passare.
- **Montagne Russe**: saliscendi ripidi, un trampolino e un tratto finale a dentiera.
